# CVE-2026-112621

SwiftUI test app with a link-preview area, a `Run PoC` button, and an in-memory run log. The log is cleared when the app process restarts.

## Build with GitHub Actions

1. Push the project to a repository.
2. Open **Actions** and run **Build CVE-2026-112621** (or push a commit).
3. Download the `CVE-2026-112621-IPA` artifact.

The IPA is unsigned.
